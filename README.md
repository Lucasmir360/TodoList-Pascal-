# TodoList Pascal

Um gerenciador de tarefas desenvolvido em Pascal, executado diretamente pelo terminal.

## Funcionalidades

- Adicionar tarefas
- Listar tarefas cadastradas
- Marcar tarefas como concluídas
- Remover tarefas
- Menu interativo pelo terminal

## Tecnologias

- Pascal
- Free Pascal Compiler (FPC)

## Como executar

Compile o programa:

```bash
fpc TodoList.pas
```

Execute:

```bash
./TodoList
```

## Observação

As tarefas são armazenadas apenas durante a execução do programa. Ao encerrá-lo, os dados são perdidos.
